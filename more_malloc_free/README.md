
# 0x0B. More malloc, free

## Description

This project focuses on dynamic memory allocation in C using malloc and free.

## Files

- 0-malloc_checked.c: Allocates memory using malloc and checks allocation failure.
- 1-string_nconcat.c: Concatenates two strings.
- 2-calloc.c: Allocates memory for an array and initializes it to zero.
- 3-array_range.c: Creates an array of integers from min to max.
- main.h: Contains function prototypes.

## Compilation

gcc -Wall -pedantic -Werror -Wextra -std=gnu89

## Concepts

- malloc
- free
- calloc
- Dynamic memory allocation
- Memory management
